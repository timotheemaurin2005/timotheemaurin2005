## ⚡ What I'm Building

I'm obsessed with **agentic AI** — systems that don't just call an LLM in a loop, but actually *plan, route, retrieve, verify, and self-correct*. The kind of systems where you can explain every decision the agent made and prove it didn't hallucinate.
